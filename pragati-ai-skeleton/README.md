# PRAGATI AI

AI-powered infrastructure project monitoring and early-warning platform.

## Architecture

Frontend: React + TypeScript + Tailwind CSS
Backend: FastAPI + SQLAlchemy
Database: PostgreSQL
ML: Python + scikit-learn + XGBoost
Explainability: SHAP
Deployment: Docker

## Repository Structure

- `frontend/` — React frontend
- `backend/` — FastAPI backend
- `ml/` — data science and ML pipelines
- `data/` — raw, processed and mock data
- `database/` — database scripts/migrations
- `scripts/` — utility scripts
- `docs/` — architecture and product documentation

## Quick Start

The initial skeleton intentionally contains minimal placeholder code. Build each module incrementally.

See `docs/architecture.md` and `docs/team-division.md`.
